# CLI_Todo_app

A simple Command Line Interface (CLI) To-Do List application built using Python.

## Features

- Add new tasks
- Delete existing tasks
- Mark tasks as completed
- View all tasks with completion status
- Save tasks using file handling
- Load saved tasks when the application starts

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops and Conditional Statements
- File Handling

## How It Works

Tasks are stored in a text file (`tasks.txt`) along with their completion status. When the application starts, tasks are loaded from the file. Any changes made to tasks are automatically saved back to the file.

## How to Run

1. Clone the repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python todo.py
```

## Menu Options

1. Add Task
2. Delete Task
3. Mark Task as Completed
4. List Tasks with Status
5. Exit
