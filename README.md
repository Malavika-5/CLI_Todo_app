# CLI_Todo_app

A simple Command Line Interface (CLI) To-Do List application built using Python.

Features
Add new tasks
View all tasks with completion status
Mark tasks as completed
Delete tasks
Store tasks permanently using file handling
Load saved tasks when the application starts
Technologies Used
Python
Lists
Dictionaries
Loops and Conditional Statements
File Handling
File Storage

Tasks are stored in a text file (tasks.txt) so that data persists even after the application is closed.

Each task is stored along with its completion status.

How to Run
Clone or download the project.
Open a terminal in the project directory.
Run the following command:
python todo.py
Menu Options
Add Task
Delete Task
Mark Task as Completed
List Tasks with Status
Exit
